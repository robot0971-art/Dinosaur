# 3D 3인칭 공룡 성장형 게임 상세 기획서

## 1. 문서 목적

이 문서는 초보자 게임개발자가 Unity 3D로 구현을 시작할 수 있도록 만든 `3D 3인칭 공룡 성장형 게임` 상세 기획서다.

참고 링크는 YouTube의 `Mini game fishdom ads, help the fish` 계열 영상으로 확인된다. 영상의 세부 장면은 직접 확인하기 어렵지만, 제목과 요청 내용을 기준으로 핵심 구조를 `작은 대상부터 먹고 성장해서 더 큰 대상을 먹는 게임`으로 해석한다.

이 기획서는 그 구조를 더 단순하게 바꿔서 공룡 게임으로 만든다.

## 2. 게임 한 줄 소개

작은 공룡으로 시작해 내 레벨보다 작거나 같은 공룡을 잡아먹고 경험치를 얻어 성장하며, 내 레벨보다 높은 공룡을 피하면서 레벨 20까지 성장하는 3D 3인칭 성장형 액션 게임.

## 3. 핵심 규칙 요약

| 조건 | 결과 |
|---|---|
| 플레이어 레벨 > 적 레벨 | 먹을 수 있다. EXP를 얻는다. |
| 플레이어 레벨 = 적 레벨 | 먹을 수 있다. EXP를 얻는다. |
| 플레이어 레벨 < 적 레벨 | 먹을 수 없다. 충돌하면 즉시 게임오버. |

이번 기획서에서 가장 중요한 규칙은 다음과 같다.

- 플레이어보다 낮은 레벨 공룡은 먹을 수 있다.
- 플레이어랑 같은레벨 공룡은 먹을수 없다.
- 플레이어보다 높은 레벨 공룡은 절대 먹을 수 없다.
- 높은 레벨 공룡과 충돌하면 바로 게임오버된다.
- 체력 시스템은 사용하지 않는다.
- 성장 판단은 레벨과 경험치만 사용한다.



## 4. 게임 장르와 방향

| 항목 | 내용 |
|---|---|
| 장르 | 3D 3인칭 성장 액션 |
| 시점 | 플레이어 뒤를 따라가는 3인칭 카메라 |
| 핵심 플레이 | 이동, 추격, 회피, 먹기, 성장 |
| 전투 방식 | 공격 버튼 없이 충돌 기반 먹기 판정 |
| 성장 방식 | 적 레벨만큼 EXP 획득 후 레벨업 |
| 실패 조건 | 높은 레벨 공룡과 충돌하면 게임오버 |
| 목표 | 레벨 20까지 성장 |
| 추천 엔진 | Unity 3D |
| 그래픽 스타일 | 귀여운 로우폴리 3D 공룡 |

## 6. 플레이어 목표

플레이어의 목표는 단순하다.

1. 내 레벨보다 작은 공룡을 찾는다.
2. 그 공룡에게 접근한다.
3. 충돌해서 먹는다.
4. 먹은 공룡의 레벨만큼 EXP를 얻는다.
5. EXP가 차면 레벨업한다.
6. 몸집이 커진다.
7. 이전에는 피해야 했던 더 큰 공룡을 먹을 수 있게 된다.
8. 레벨 20까지 성장한다.

## 7. 플레이 감정 목표

이 게임에서 플레이어가 느껴야 하는 감정은 다음과 같다.

| 상황 | 플레이어 감정 |
|---|---|
| 처음 시작 | 나는 작고 약하다. 조심해야 한다. |
| 낮은 레벨 공룡 발견 | 저건 먹을 수 있겠다. |
| 높은 레벨 공룡 발견 | 지금은 피해야 한다. |
| 레벨업 | 몸집이 커졌다. 더 강해졌다. |
| 이전에 못 먹던 공룡을 먹음 | 성장한 것이 확실히 느껴진다. |
| 레벨 20 도달 | 최상위 포식자가 되었다. |

## 8. 체력 없는 게임오버 규칙

이 게임에는 체력이 없다. 하트 UI도 없다. 피해량 계산도 없다.

대신 규칙을 아주 단순하게 만든다.

```text
플레이어 레벨보다 높은 공룡과 충돌하면 즉시 게임오버
```

### 8.1 체력을 없애는 이유

초보자 개발 기준에서 체력, 피해량, 무적 시간, 회복 아이템까지 만들면 구현 범위가 커진다. 이 게임은 성장 판단이 핵심이므로 체력을 제거하고 레벨 비교만 사용한다.

### 8.2 게임오버 예시

| 플레이어 레벨 | 충돌한 적 레벨 | 결과 |
|---:|---:|---|
| 1 | 1 | 먹기 성공 |
| 1 | 2 | 게임오버 |
| 5 | 3 | 먹기 성공 |
| 5 | 5 | 먹기 성공 |
| 5 | 6 | 게임오버 |
| 12 | 12 | 먹기 성공 |
| 12 | 13 | 게임오버 |

## 9. 경험치와 레벨업 규칙

### 9.1 기본 공식

```text
먹은 공룡에게서 얻는 EXP = 먹은 공룡의 레벨
다음 레벨 필요 EXP = 현재 플레이어 레벨의 약 60%, 소수점 올림
EXP가 필요량 이상이면 레벨 +1
레벨업 후 남은 EXP는 유지
```

초보자용 공식은 다음과 같이 생각하면 된다.

```text
필요 EXP = 올림(현재 레벨 x 0.6)
```

예를 들어 현재 레벨이 5라면 필요 EXP는 10이다.

```text
5 x 0.6 = 3
레벨 5에서 다음 레벨까지 필요한 EXP = 10
```

### 9.2 요청 예시 반영

요청한 예시처럼 `내가 레벨 5이고 적이 레벨 4이면, 적을 먹었을 때 레벨 6이 되는 구조`를 만든다.

```text
현재 상태: 플레이어 Lv.5, EXP 0/100
먹은 적: Lv.4 공룡
획득 EXP: +50
결과 EXP: 50/100
레벨업 발생
최종 상태: 플레이어 Lv.6, EXP 0/100
```

이 방식이면 레벨 4 적을 먹었을 때 단순히 점수만 오르는 방식이다.

### 9.3 여러 마리를 먹어서 레벨업하는 예시

```text
현재 상태: 플레이어 Lv.6, EXP 0/4
Lv.2 공룡 먹음: EXP +10, 현재 EXP 10/100
Lv.1 공룡 먹음: EXP +30, 현재 EXP 30/100
Lv.1 공룡 먹음: EXP +50, 현재 EXP 50/100
레벨업 발생
최종 상태: 플레이어 Lv.7, EXP 0/100
```

### 9.4 남은 EXP 유지 예시

```text
현재 상태: 플레이어 Lv.6, EXP 50/100
Lv.4 공룡 먹음: EXP +50
합산 EXP: 50/100
레벨업에 50 사용
최종 상태: 플레이어 Lv.7, EXP 0/100
```

남은 EXP를 유지하면 플레이어가 강한 적을 먹었을 때 보상이 낭비되지 않는다.

## 12. 플레이어 성장 외형 단계

레벨마다 플레이어 모델을 전부 바꾸면 작업량이 많다. 초보자라면 같은 공룡 모델을 사용하고 크기만 키우는 방식으로 시작한다.

| 레벨 구간 | 외형 변화 | 설명 |
|---|---|---|
| 1~4 | 새끼 공룡 | 작고 귀여운 시작 단계 |
| 5~8 | 어린 공룡 | 몸집이 커지고 이빨이 보임 |
| 9~12 | 중형 공룡 | 꼬리와 머리가 커짐 |
| 13~16 | 대형 공룡 | 발소리가 묵직해짐 |
| 17~20 | 최상위 포식자 | 어두운 색, 큰 이빨, 강한 포효 |

## 13. 기본 게임 흐름

1. 타이틀 화면에서 시작 버튼을 누른다.
2. 플레이어는 레벨 1 작은 공룡으로 시작한다.
3. 화면에는 레벨 1~3 공룡이 보인다.
4. 플레이어는 자기보다 작거나 같은 레벨 공룡을 먹는다.
5. 플레이어보다 높은 레벨 공룡은 피한다.
6. 먹은 공룡의 레벨만큼 EXP를 얻는다.
7. EXP가 차면 레벨업한다.
8. 레벨업하면 플레이어 몸집이 커진다.
9. 새로 먹을 수 있는 공룡 범위가 넓어진다.
10. 높은 레벨 공룡에게 닿으면 게임오버된다.
11. 레벨 20에 도달하면 클리어된다.

## 15. 카메라 기획

카메라는 플레이어 뒤를 따라가는 3인칭 카메라다.

| 항목 | 추천값 |
|---|---|
| 카메라 기본 거리 | 6 |
| 카메라 기본 높이 | 4 |
| 카메라 회전 | 마우스 좌우 회전 |
| 카메라 줌 | 레벨업 시 조금 멀어짐 |
| 카메라 충돌 | 첫 버전에서는 생략 가능 |

### 15.1 레벨별 카메라 거리

| 레벨 구간 | 카메라 거리 | 카메라 높이 |
|---|---:|---:|
| 1~4 | 6 | 4 |
| 5~8 | 7 | 4.5 |
| 9~12 | 8 | 5 |
| 13~16 | 9 | 6 |
| 17~20 | 10 | 7 |

몸집이 커질수록 카메라가 멀어져야 플레이어 몸이 화면을 너무 많이 가리지 않는다.

## 16. 먹기 판정 기획

먹기 판정은 공격 버튼 없이 충돌로 처리한다.

### 16.1 판정 순서

```text
플레이어가 적 공룡과 충돌
적 공룡의 레벨 확인
플레이어 레벨과 적 레벨 비교
플레이어 레벨 >= 적 레벨이면 먹기 성공
플레이어 레벨 < 적 레벨이면 게임오버
```

### 16.2 먹기 성공 연출

| 단계 | 연출 |
|---|---|
| 1 | 플레이어가 적에게 닿음 |
| 2 | 적이 잠깐 작아짐 |
| 3 | 적이 사라짐 |
| 4 | `EXP +3` 같은 숫자 표시 |
| 5 | EXP 바 증가 |
| 6 | 필요 EXP가 차면 레벨업 효과 발생 |

### 16.3 게임오버 연출

| 단계 | 연출 |
|---|---|
| 1 | 플레이어가 높은 레벨 공룡과 충돌 |
| 2 | 화면이 잠깐 빨갛게 변함 |
| 3 | 시간이 느려지는 느낌 연출 |
| 4 | 플레이어가 넘어지는 애니메이션 또는 사라짐 |
| 5 | `GAME OVER` 표시 |
| 6 | 다시 시작 버튼 표시 |

첫 버전에서는 애니메이션 없이 `GAME OVER` UI만 띄워도 된다.

| EXP 바 | 상단 중앙 | EXP 1 / 3 | 다음 레벨까지 남은 경험치 표시 |
| 목표 문구 | 중앙 상단 | 내 레벨 이하 공룡을 먹으세요 | 플레이 방향 안내 |
| 적 레벨 표시 | 적 머리 위 | Lv. 3 | 먹을 수 있는지 판단 |

| 클리어 화면 | 중앙 | LEVEL 20 CLEAR | 승리 상태 표시 |

### 17.2 색상 규칙

| 적 상태 | 색상 | 의미 |
|---|---|---|
| 플레이어보다 낮은 레벨 | 초록 | 안전하게 먹을 수 있음 |
| 플레이어와 같은 레벨 | 파랑 | 먹을 수 있음, 좋은 성장 대상 |
| 플레이어보다 높은 레벨 | 빨강 | 충돌하면 게임오버 |

같은 레벨도 먹을 수 있으므로 노란색 경고가 아니라 파랑색 또는 하늘색으로 표시하는 것을 추천한다.

## 29. 초보자 구현 팁

- 처음부터 예쁜 공룡 모델을 찾지 말고 Capsule으로 먼저 만든다.
- 레벨 1 공룡은 Sphere로 공룡 알처럼 만들면 쉽다.
- 빨간색 공룡은 위험하다는 의미로 사용한다.
- 같은 레벨은 먹을 수 있으므로 위험 색으로 표시하지 않는다.
- 게임오버는 체력 없이 `한 번 충돌하면 끝`으로 만든다.
- 레벨 1~3까지 먼저 완성한 뒤 레벨 20까지 확장한다.
- UI는 반드시 먼저 넣는다. 레벨과 EXP가 보여야 테스트가 쉽다.
- 스폰 시스템은 나중에 만든다. 처음에는 손으로 공룡을 배치해도 된다.

## 30. 최종 요약

이 게임의 핵심은 아주 단순하다.

```text
내 레벨보다 작거나 같은 공룡은 먹는다.
내 레벨보다 높은 공룡은 피한다.
먹으면 EXP가 오른다.
EXP가 차면 레벨이 오른다.
레벨이 오르면 몸집이 커지고 더 큰 공룡을 먹을 수 있다.
높은 레벨 공룡과 충돌하면 체력 없이 바로 게임오버된다.
```

초보자 개발 기준으로는 먼저 레벨 1~3만 구현해서 `먹기`, `EXP`, `레벨업`, `게임오버`가 제대로 작동하는지 확인한다. 그 다음 레벨별 공룡 데이터를 20까지 늘리고, 마지막에 스폰, 사운드, 이펙트, 맵 꾸미기를 추가하는 방식이 가장 안전하다.
