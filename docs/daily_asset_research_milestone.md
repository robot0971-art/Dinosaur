# Dino Grow 3D 오늘 마일스톤

## 1. 문서 목적

이 문서는 `dino_3d_growth_game_design.md` 기획서를 기준으로 오늘 하루 동안 진행할 `에셋 자료 찾기 전용 마일스톤`이다.

오늘은 Unity 개발, 코드 작성, 씬 제작, 프리팹 제작을 하지 않는다. 오늘의 목표는 게임을 만들기 전에 필요한 에셋 후보를 찾고, 사용할 수 있는지 라이선스와 스타일을 확인하고, 나중에 Unity 프로젝트에 넣을 수 있도록 정리하는 것이다.

## 2. 오늘의 최종 목표

오늘 하루가 끝났을 때 아래 결과물이 있어야 한다.

1. 공룡 20레벨에 사용할 3D 공룡 에셋 후보를 찾는다.
2. 플레이어 공룡으로 사용할 메인 공룡 에셋 후보를 찾는다.
3. 초원 맵에 사용할 환경 에셋 후보를 찾는다.
4. 각 에셋의 다운로드 링크, 가격, 라이선스, 파일 형식, 사용 가능 여부를 표로 정리한다.
5. 오늘 찾은 에셋 중 `바로 사용할 후보`, `보류`, `사용하지 않을 후보`를 구분한다.

## 3. 오늘 하지 않을 일

오늘은 에셋 자료 찾기만 한다.

| 하지 않을 일 | 이유 |
|---|---|
| Unity 프로젝트 생성 | 오늘은 자료 조사일이다. |
| 코드 작성 | 에셋 방향을 먼저 정해야 한다. |
| 씬 제작 | 맵 에셋 후보를 찾은 뒤 진행한다. |
| 프리팹 제작 | 실제 다운로드 후 별도 작업일에 진행한다. |
| 애니메이션 연결 | 공룡 에셋 확정 후 진행한다. |
| 밸런스 테스트 | 아직 구현 단계가 아니다. |
| 유료 에셋 결제 | 후보 조사 후 비교해서 결정한다. |

## 4. 오늘의 에셋 탐색 기준

초보자 개발 기준에서는 멋진 에셋보다 `쉽게 쓸 수 있는 에셋`이 더 중요하다.

### 4.1 공통 평가 기준

| 기준 | 확인 내용 |
|---|---|
| 라이선스 | 상업적 사용 가능 여부, 출처 표기 필요 여부 |
| 가격 | 무료인지, 유료인지, 예산 안에 들어오는지 |
| 파일 형식 | Unity에서 사용하기 쉬운 FBX, PNG, WAV, MP3인지 |
| 스타일 | 로우폴리, 카툰, 귀여운 스타일과 맞는지 |
| 작업 난이도 | 초보자가 바로 넣어 쓸 수 있는지 |
| 애니메이션 | Idle, Walk, Run, Eat, Die 같은 기본 애니메이션이 있는지 |
| 용량 | 너무 무겁지 않은지 |
| 일관성 | 다른 에셋과 함께 써도 어색하지 않은지 |

### 4.2 우선순위 기준

| 우선순위 | 기준 |
|---:|---|
| 1 | Unity에서 바로 쓸 수 있음 |
| 2 | 무료 |
| 3 | 로우폴리/카툰 스타일 |
| 4 | 애니메이션 포함 |
| 5 | 같은 제작자의 패키지로 여러 공룡 제공 |

2. 라이선스 문서를 따로 저장한다.
3. Unity 프로젝트를 만든다.
4. `Assets/DownloadedAssets` 폴더를 만든다.
5. 플레이어 공룡 후보 1개를 넣어본다.
6. 레벨 1~3 공룡만 먼저 배치한다.
7. 모델 크기와 충돌 범위를 확인한다.
